Osu3tja 譜面轉換器

把 osu! 譜面（.osz）轉成太鼓模擬器用的 TJA

怎麼使用？三個步驟

  1. 準備 .osz 檔。從 osu! 官網下載譜面（建議挑「osu!taiko」模式的譜面），檔案副檔名是 .osz。
  2. 把檔案拖進下方的框框，接著為魔王／困難／普通／簡單選好要用哪一份譜面，按「開始轉換」。
  3. 下載 ZIP 並解壓縮，把整個資料夾放進你的太鼓模擬器（如 TJAPlayer3、太鼓次郎）的歌曲資料夾即可。

難度對應

為每個太鼓難度選一份 osu! 譜面；選「不輸出」則略過該難度。右側的星數可自訂（1～10），留空就使用預設值。

儲存位置

會在這個資料夾裡建立一個以歌名命名的子資料夾（已存在就加編號，不會覆蓋）。

進階設定

若在播放器裡看到亂碼，請換一種編碼再轉換一次。

✔ 轉換完成

接下來：下載 ZIP → 解壓縮 → 把整個資料夾（內含 .tja 與音檔）放進播放器的歌曲資料夾，重新掃描歌曲即可。
